# Prodesk Mission 8

This project was developed as part of Mission 8 assignment.  
The application is built using modern frontend technologies and focuses on responsive UI, clean design, and component-based architecture.

## Features

- Responsive user interface
- Modern React-based frontend
- Reusable components
- Clean folder structure
- Fast development using Vite
- Easy to maintain code

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS / Tailwind CSS
- Git & GitHub
